| ChEMBL 37 calculated molecule properties (mol weight, ALogP, polar surface area, weighted QED, rule-of-five violations) for the trials' lead drugs | https://www.ebi.ac.uk/chembl/api/data/molecule.json (public REST API, 50 ids per request; release checked with `status.json`) | 11 Nov 2026 (release dated 1 May 2026) | `data/raw/chemistry/chembl_properties.csv` | 1,965 drugs, 65 KB (65,464 bytes). No pinned ChEMBL 37 bulk file carries these properties at a usable size (the properties live in the 5 GB SQLite release), so the API route stays. `chemistry.fetch_properties` rebuilds the file, retries on errors, refuses a different release and tolerates a status page that names none, and its output is checked against the sha256 above. A test runs it against a response in the API's shape. |
| Pretrained language models `claude-haiku-5-5` and `claude-sonnet-5-5` (Anthropic), called through the Claude Code command line | https://www.anthropic.com | 11 Nov 2026 (development dry run of the first two frozen batches; the full run date is added when it is made) | `data/interim/llm_predictions.parquet`, raw replies in `data/interim/llm_raw/` | Pretrained models, not data. Used only by the language-model-as-predictor family (`llm_predictor.py`). Each call has no tools, no settings or memory, an empty working directory and a minimal environment (PATH, HOME, USER, LOGNAME), and sees a plain-text protocol record (no results, summary, status, completion dates or enrolment). Our own system prompt is given, but the command line still adds two blocks to every call, the same for every variant: an environment block (empty working directory, operating system, shell, the model's name and id, its knowledge cut-off, which both models report as June 2026, and today's date) and a short block holding the account email. The model is therefore told today's date and its own cut-off. The calls go to the same provider, signed in as the same account, as everything else in this project; no API key, and no email address or other personal detail is stored in this repository. The model id the tool reports must equal the one asked for, or the call fails. Each raw reply file keeps the exact prompt sent, its sha256, the system prompt, the command line and a time. Not used by the pre-registered baselines. |
